S-03. 로딩

관련 기능 F-04~11 · 기준: SCREENS.md 3장 S-03 · 프레임 1280×760. 진행 단계는 통계 불러오기 → 코인 생성 → 시세 생성 → 이벤트 준비. 모든 시안은 "코인 생성" 단계 중간(10개 중 6개 생성) 순간을 그렸다.

시안 A. 가운데 단계 목록 + 코인 이름 목록

의도: 왼쪽에는 지금 몇 단계인지, 오른쪽에는 생성되는 코인 이름이 한 줄씩 추가된다. 기다리는 동안 "이번 판에 어떤 코인이 나오는지"를 미리 읽게 한다.

걱정되는 점
  • 로딩이 짧으면(1~2초) 다 읽기 전에 넘어감
  • 게임 화면과 모양이 달라 전환이 뚝 끊김

시안 B. 게임 화면 골격 위에서 채워짐

의도: 선택한 게임 화면(S-04 시안 C)의 골격을 먼저 그리고, 코인 카드가 하나씩 채워진다. 로딩이 끝나면 그 자리에서 바로 준비 상태로 넘어가 화면 전환이 없다.

좋은 점
  • 로딩 → 게임 전환이 자연스러움
  • 게임 화면 배치를 미리 익히게 됨
걱정되는 점
  • 로딩 화면을 게임 화면 구현에 묶어야 함 (만드는 순서 영향)
  • 오류 화면은 따로 필요

시안 C. 큰 진행 막대 + 코인 카드 격자 — ✔ 선택

의도: 코인 10개를 5×2 카드로 크게 보여 주는 "출전 명단" 느낌의 연출. 카드가 뒤집히듯 하나씩 공개된다.
