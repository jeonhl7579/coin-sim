## 1. 디자인 방향

- 거래소 배치에 게임 연출을 섞는다. 화면은 **심플한 금융 느낌**으로 두고, 연출은 이벤트·체결·로딩(코인 카드 공개)·결과(매매 그래프 재생과 등급) 네 곳에 모은다.
- MVP는 어두운 테마 하나로 시작한다.

| 용도 | 색 (시안) | 비고 |
|---|---|---|
| 배경 | 짙은 남색 `#0F1623` | |
| 패널 | `#172131` | 경계선 `#243046` |
| 본문 글자 / 보조 글자 | `#E6EAF0` / `#8A94A6` | |
| 강조 (버튼, 선택 상태) | 골드 `#D4A84B` | 파랑은 하락색이라 강조색으로 쓰지 않음 |
| 상승 / 하락 | 빨강 `#F04452` / 파랑 `#3182F6` | ▲▼ 기호와 함께 표시 (NFR-13) |

- 색 값은 시안 **[테스트 후 결정]**

## 3. 화면별 상세

### S-01. 모바일 안내

| 구분 | 내용 |
|---|---|
| 구성 요소 | 로고, 게임 소개 한 줄, "데스크톱에서 플레이해 주세요" 안내와 이유 한 줄("차트와 주문 패널을 한 화면에 보여 줘야 해서 1280px 이상 화면이 필요해요"), 주소 복사 버튼(가장 크게), 주소 텍스트 |
| 사용자 동작 | 주소 복사 → "주소를 복사했어요" 안내 |
| 이동 | 없음 |
| 예외 처리 | 기기 판정이 틀릴 수 있으므로 화면 너비와 기기 정보를 함께 판정 **[추측]** / 복사 실패(클립보드 권한 없음) → 주소 칸을 선택 상태로 두고 "길게 눌러 직접 복사" 안내 |

### S-02. 메인

| 구분 | 내용 |
|---|---|
| 구성 요소 | 가운데 한 열로 배치. 로고와 한 줄 소개 / [게임 시작] (가장 크게) / [기록 보기] / 최근 기록 요약 (최고 등급, 최근 수익률) / "투자 권유가 아님" 고지 / [이어 하기] (2차) / [도움말] (MVP 이후) |
| 사용자 동작 | 각 버튼 클릭 |
| 이동 | → S-03, S-06 |
| 예외 처리 | 기록이 없으면 요약 대신 "첫 판을 시작해 보세요" / localStorage를 쓸 수 없으면 "기록이 저장되지 않습니다" 안내 |

### S-03. 로딩

| 구분 | 내용 |
|---|---|
| 구성 요소 | 진행 단계 표시 (통계 불러오기 → 코인 생성 → 시세 생성 → 이벤트 준비) / 이번 판 코인 10개를 5×2 카드 격자로 표시. 빈 카드("?")가 생성 순서대로 하나씩 공개되고, 카드에 티커·이름·성격(대장~밈) 태그. 폭락형은 원래 자리의 성격으로 표시하고 공개하지 않음 / 짧은 팁 문구 |
| 사용자 동작 | 없음 (대기) |
| 이동 | 완료 → S-04 (준비 상태) |
| 연출 | 카드 공개 연출을 보여 주려고 로딩을 일부러 늘리지 않는다. 생성이 빠르면 카드를 짧은 간격으로 연달아 공개 **[임시값]** |
| 예외 처리 | 불러오기 실패 → 오류 안내 + [다시 시도] / [메인으로] / 생성 결과가 비정상이면 다른 시드로 자동 재생성 ("시세 다시 생성 중" 문구만 바뀜) |

### S-04a. 이벤트 모달

모달이 떠 있는 동안은 **일시정지 상태**다. 선택지를 골라야 재생이 재개된다.

> **기준 문서:** 모달 동작(일시정지, 직접 주문, 접기, 선택 유도)은 이 절이 기준이다. 체결 가격은 [FEATURES.md](FEATURES.md) 2장이 기준이고, 아래 "체결 가격" 행은 요약. 수정은 기준 문서에서 먼저.

화면 형태는 **오른쪽 사이드 시트**(폭 약 440px **[임시값]**)다. 이름은 다른 문서와 맞춰 "이벤트 모달"로 둔다. 시트는 어차피 잠기는 주문 패널 자리를 덮고, 왼쪽(코인 카드, 차트)은 옅게만 덮어서 접지 않고도 차트를 보며 판단할 수 있게 한다.

```
펼친 상태 (오른쪽 사이드 시트)                       접은 상태 (차트 박스 맨 위에 띠로 표시)
┌──────────────────────────┬──────────────────┐     ┌────────────────────────────────────────┐
│ 코인 카드 · 차트            │ ⚠ 속보      [접기 ▾] │     │ ⚠ 이벤트 대기 중: "JLT 해킹 의혹" [펼치기 ▴] │
│ (옅게 덮임, 카드 눌러        │ "JLT 상장 거래소     │     └────────────────────────────────────────┘
│  차트 전환 가능)            │  해킹 의혹 제기"      │
│                          │ 본문 (전파 힌트)      │     직접 주문을 연 상태 (시트 안)
│                          │ ┌ 영향 코인 ───────┐ │     ┌──────────────────┐
│                          │ │ JLT 처음 ▼8.2%   │ │     │ 뉴스 · 영향 · 내 보유 │
│                          │ │ HXA 전파 우려     │ │     │ 직접 주문  [← 선택지] │
│                          │ └─────────────────┘ │     │ 코인 [JLT ▾]       │
│                          │ ┌ 내 보유 ─────────┐ │     │ (S-04 주문 패널)    │
│                          │ │ JLT 1,200개      │ │     │ 이번 이벤트 주문 목록  │
│                          │ │ 평가 −336,000    │ │     │ [주문 완료하고 재개]  │
│                          │ └─────────────────┘ │     └──────────────────┘
├──────────────────────────┤ 어떻게 할까요?        │
│ 보유 현황 일부는 시트에 가림   │ [전량 매도]           │
│ (시트 안 "내 보유"로 대신)    │  1,200개 · 약 3.1M 확보│
│                          │ [절반 매도] …         │
│                          │ [그대로 보유] …       │
│                          │ [현금 30%로 추가 매수] │
│                          │ [직접 주문 ▾]         │
└──────────────────────────┴──────────────────┘
```

| 구분 | 내용 |
|---|---|
| 구성 요소 | 뉴스 제목과 본문(전파 힌트 포함) / 영향 코인(처음 발생·전파 우려)과 현재 등락 / 내 보유 상황 / 선택지 버튼 (버튼마다 결과 미리보기 한 줄, 예: "JLT 1,200개 · 약 3,124,800 확보") / 체결 가격 안내 한 줄 / 직접 주문 입력란 / 접기 버튼 |
| 사용자 동작 | 선택지 고르기 → 체결 → 남은 충격 반영 → 재생 재개 / [그대로 보유] = 아무것도 하지 않고 재개 / [접기]·[펼치기] |
| 직접 주문 | [직접 주문]을 누르면 모달 **안에서** 선택지 자리를 주문 입력란이 대신함 (S-04 주문 패널 컴포넌트를 재사용). [← 선택지]로 돌아갈 수 있음. 어느 코인이든 여러 건 주문 가능. [주문 완료하고 재개]로 끝냄 |
| 체결 가격 | 처음 발생한 코인은 충격이 절반 반영된 가격 / 전파되는 코인은 반영 전 가격 / 나머지는 현재가 |
| 접기의 역할 | 펼친 상태에서도 차트와 코인 전환은 보이지만, 시트가 가리는 보유 현황·대기 주문까지 보려면 접는다. 접은 상태는 **보는 용도로만** 사용. 접은 상태에서도 일시정지가 유지되고 바깥 주문 패널은 잠김 |
| 선택 유도 | 접은 상태에서 [재생]을 누르면 재생되지 않고 모달이 다시 펼쳐짐 ("선택지를 골라야 재개됩니다") / 접은 상태가 일정 시간(예: 15초) 이어지면 띠가 깜빡임 **[테스트 후 결정]** |
| 이동 | 선택을 마치면 S-04로 돌아가 원래 배속으로 재생 |
| 예외 처리 | 배속 변경 불가 / 그만두기는 가능 / 선택지·직접 주문이 실패하면(현금 부족 등) 모달을 유지하고 이유 표시 / 같은 캔들의 여러 이벤트는 A(묶음)·B(순서대로)를 설정값으로 전환 **[테스트 후 결정]** |

### S-04b. 그만두기 확인 창

| 구분 | 내용 |
|---|---|
| 구성 요소 | 화면 가운데 작은 확인 창 (화면 전체를 어둡게 덮음). "게임을 그만둘까요?" / "지금 그만두면 현재 가격으로 결과가 확정됩니다. 기록에 중도 종료로 남습니다." / 현재 수익률 / [계속하기](주 버튼) [그만두기] |
| 사용자 동작 | 둘 중 하나 선택 |
| 이동 | 계속하기 → S-04 (일시정지 상태) / 그만두기 → S-05 (중도 종료 표시) |
| 예외 처리 | 이벤트 모달이 떠 있을 때: 시트까지 덮고 확인 창을 한 겹 더 띄움. 문구에 "이벤트 선택지는 적용되지 않습니다" 추가, 버튼은 [계속하기 (이벤트로)] → S-04a로 돌아감 |

### S-05. 결과
