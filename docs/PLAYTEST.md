# Coin Sim — 테스트 후 결정 항목

- 작성일: 2026-11-12
- 상태: 관리 중 (테스트할 때마다 "결정" 열을 채운다)
- 관련 문서: [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md), [FEATURES.md](FEATURES.md), [PROCESS.md](PROCESS.md), [SCREENS.md](SCREENS.md)
- 이 문서는 다른 문서에서 **[테스트 후 결정]**으로 표시한 항목을 모은 목록이다.
- 값을 정하면 아래 순서로 처리한다.
  1. 기준 문서의 값을 고친다.
  2. 이 표의 "결정" 열에 결과와 날짜를 적는다.
  3. 기준 문서에서 [테스트 후 결정] 표시를 지운다.
