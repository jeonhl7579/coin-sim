## 2. 주요 사용자 흐름

### P-1. 접속과 메인 화면
```
접속 → 기기 판정
  ├ 모바일 → 데스크톱 이용 안내 화면 (F-34) → 끝
  └ 데스크톱 → 메인 화면
       → [게임 시작] → P-2
       → [기록 보기] → P-7
       → [도움말] (MVP 이후)
       → [이어 하기] (2차, 저장된 판이 있을 때만) → P-10
```

### P-2. 게임 준비
```
[게임 시작] → 로딩 화면
  → 통계 JSON 불러오기
  → 시드 정하기 → 가상 코인 10개 생성
  → 캔들 생성 (과거 100개 + 본게임 600개) → 이벤트 생성
→ 준비 상태 (일시정지된 상태로 게임 화면 진입)
  → 코인 목록, 과거 차트, 코인 소개 보기
  → (선택) 첫 매수: 시장가는 과거 구간의 마지막 종가로 체결, 지정가 걸기 가능
→ [재생] → P-3
```

### P-3. 플레이 (반복)
```
세부 단계마다: 가격 갱신 → 지정가 체결 판정 (그 세부 단계 가격으로 체결) → 이벤트 확인 (→ P-4)
캔들이 끝날 때마다: 캔들 확정 → 다음 캔들
600번째 캔들이 끝나면 → P-5
```
- 플레이 중 할 수 있는 것: 코인 선택, 매수·매도(시장가·지정가), 주문 취소, 배속 변경, 일시정지와 재개, 그만두기(→ P-6)

### P-4. 이벤트

> 기준: 체결 가격·전파 규칙은 [FEATURES.md](FEATURES.md) 2장, 모달 동작은 [SCREENS.md](SCREENS.md) S-04a. 수정은 기준 문서에서 먼저.

```
이벤트 발생 → 선택지를 띄울 조건인지 판정
  ├ 해당 없음 → 뉴스 피드에 기사 표시, 계속 재생
  └ 해당 → 체결 가격 시점에서 일시정지
          (처음 발생한 코인은 절반 반영, 전파되는 코인은 반영 전)
        → 이벤트 모달: 뉴스, 영향받는 코인, 선택지 (모달이 떠 있는 동안은 일시정지)
        ├ 선택지 → 체결
        └ [직접 주문] → 모달 안의 주문 입력란에서 여러 건 주문 → [주문 완료하고 재개]
        → 남은 충격 반영 (즉시 전파 대상 코인의 결과 포함, 뉴스 피드에 후속 기사) → 원래 배속으로 재생 재개
늦게 전파되도록 예약된 충격 → 1~3캔들 뒤 반영, 뉴스 피드에 후속 기사 (모달 없음, 영향 없음이어도 기사)
```
- 선택지를 띄울 조건: 보유 코인이 충격을 받거나 전파를 받을 때, 또는 시장 전체 이벤트일 때
- 마지막 10캔들에서는 선택지를 띄우지 않고 뉴스 피드로만 알린다.

### P-5. 정상 종료
```
마지막 캔들 끝 → 체결되지 않은 지정가는 자동 취소, 묶인 현금 반환
  → 보유 코인을 마지막 가격으로 평가 (매도 수수료는 빼지 않음)
  → 결과 계산 (수익률, 최대 낙폭, 끝까지 보유했을 때와 비교, 등급)
  → 기록 저장 → 결과 화면
       → [다시 하기] → P-2 / [메인] → P-1 / [기록 보기] → P-7
```

### P-6. 도중에 그만두기
```
[그만두기] → 일시정지 → 확인 창
  ├ 취소 → 일시정지 상태로 게임 화면에 돌아감
  └ 확인 → P-5와 같은 종료 처리 (그 시점 가격으로 평가)
         → 결과 화면에 "중도 종료" 표시, 기록에도 구분 표시
```

### P-7. 기록 보기
```
메인 → 기록 목록 (날짜, 수익률, 등급, 중도 종료 여부) → 선택 → 그 판의 결과 화면
```

### P-8. 현실감 검증 (삭제됨)
2026-11-17 플레이어 흐름에서 뺐다. 시뮬레이터 게임의 플레이어에게는 필요 없는 화면이라, 개발자 흐름(P-9)의 검증 리포트로 옮겼다. 기준: [FEATURES.md](FEATURES.md) F-32

### P-9. 데이터 준비와 검증 (개발자 흐름)
```
수집 (F-01) → 정제 (F-02) → 통계 추출 (F-03) → JSON 내보내기 (F-04) → 게임 빌드에 포함
생성 엔진 완성 후 → 가상 시세 생성 → 실제 통계와 비교 (F-32) → 수치 조정
                 → 리포트(그래프 이미지, 수치표)를 README에 게시
```

### P-10. 저장하고 나가기 → 이어 하기 (2차)
```
[저장하고 나가기] → 일시정지 → 시드와 주문 기록을 localStorage에 저장 → 메인
메인 → [이어 하기] → 저장된 시드로 시세 재생성 → 주문 기록을 다시 적용해 상태 복원
     → 일시정지 상태로 게임 화면 진입 → [재생]
```
- [그만두기](P-6)와는 다른 버튼이다. 그만두기는 결과를 확정하고, 저장하고 나가기는 판을 이어서 할 수 있게 남긴다.
- 같은 방식으로 새로고침했을 때도 복원한다.

## 3. 분기와 예외 상황

| 구분 | 상황 | 처리 |
|---|---|---|
| 로딩 | 통계 JSON을 불러오지 못함 | 오류 안내 + [다시 시도] |
| 로딩 | 생성한 시세가 비정상 (가격 0 이하, 숫자 오류) | 다른 시드로 자동 재생성 **[테스트 후 결정]** |
| 주문 | 최소 금액 미달, 현금 부족, 보유량 부족, 지정가 입력 오류 | 주문 버튼을 비활성화하고 이유 표시 |
| 이벤트 | 같은 캔들에 이벤트가 여러 개 | A(하나의 모달로 묶음)와 B(영향이 큰 순서대로 하나씩) 두 방식을 설정값으로 구현 **[테스트 후 결정]** |
| 이벤트 | 늦게 전파된 충격이 보유 코인에 반영됨 | 모달 없이 뉴스 피드로만 알림 |
| 이벤트 | 마지막 10캔들 | 선택지 대신 뉴스 피드로만 알림 |
| 이벤트 | 모달이 떠 있을 때 | 일시정지 상태. 배속 변경 불가, 바깥 주문 패널 잠김(주문은 모달 안에서만), 그만두기는 가능 |
| 이벤트 | 모달을 접고 선택하지 않음 | [재생]을 누르면 모달이 다시 펼쳐지고 "선택지를 골라야 재개됩니다" 표시. 일정 시간 뒤 띠가 깜빡여 재촉 |
| 재생 | 사용자가 직접 일시정지(⏸)함 | 주문 가능 (가격이 움직이지 않으므로) |
| 재생 | 브라우저 탭을 옮기거나 창을 최소화함 | 자동 일시정지. 화면으로 돌아와도 자동으로 재개하지 않고 [재생]을 눌러야 함 |
| 이탈 | 새로고침하거나 창을 닫으려 함 | "진행 중인 판이 사라집니다" 경고. MVP에서는 복원하지 않음 (2차 P-10) |
| 이탈 | 게임 중(준비 상태 포함) 브라우저 뒤로 가기 | 이동을 막고 그만두기 확인 창(S-04b)을 띄움. 확인하면 P-6과 같이 처리 |
| 이탈 | 결과 화면에서 브라우저 뒤로 가기 | 끝난 게임으로 돌아가지 않음 (결과로 갈 때 기록을 대체해 이동) |
| 저장 | localStorage를 쓸 수 없거나 가득 참 | 결과 화면은 보여주고 "기록 저장 실패" 안내 |
| 화면 | 창 너비 1280px 미만 | 최소 너비를 유지하고 가로 스크롤 **[임시값]** |

> 이벤트 모달 관련 행의 기준: [SCREENS.md](SCREENS.md) S-04a. 수정은 기준 문서에서 먼저.

### 자동 일시정지 감지 방식

| 방식 | 감지하는 상황 | 적용 |
|---|---|---|
| 화면 표시 상태 (Page Visibility API) | 다른 탭으로 이동, 창 최소화, 화면 잠금 | **MVP** |
| 창 포커스 (`blur` 이벤트) | 화면은 보이지만 다른 프로그램을 클릭함 (듀얼 모니터 등) | 테스트 후 결정 **[테스트 후 결정]** |
