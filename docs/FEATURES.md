## 2. 기능별 규칙

> **기준 문서:** 이벤트 전파, 체결 가격, 주문, 등급 규칙은 이 장이 기준이다. 요약이 있는 곳: [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md) 2장, [PROCESS.md](PROCESS.md) P-4, [SCREENS.md](SCREENS.md) S-04a. 수정은 여기서 먼저.

### 이벤트 전파 (F-11)

| 요소 | 역할 | 예시 |
|---|---|---|
| 충격이 발생한 코인의 성격 | 전파 확률의 기본값 | 대장 높음, 대형 중간, 중형·소형·밈 낮음 |
| 이벤트 종류 | 전파가 일어나기 쉬운 정도 | 해킹·거래 정지는 높음 / 파트너십·상장은 낮음 |
| 받는 코인의 β | 받는 충격의 크기 | 소형·밈은 크게, 대장은 작게 |
| 전파 범위 | 어디까지 퍼지는지 | 전부 / 일부 코인 / 없음 |
| 전파 시점 | 언제 퍼지는지 | 같은 캔들 또는 1~3캔들 뒤 |
| 전파 결과 | 전파 대상 코인이 실제로 움직이는지 | 영향 있음 / 영향 없음 (별도 확률로 판정) |
| 전파 방향 | 원래 충격과 같은 쪽으로 움직이는지 | 같은 방향 / 반대 방향 (예: 경쟁 코인 해킹으로 반사 이익) |

```
이벤트 발생 → 전파 확률로 전파 여부 판정 (시드 난수)
  → 전파되면: 전파 범위(전부 / 일부 코인)와 전파 시점(즉시 / 1~3캔들 뒤 예약) 판정
              받는 코인마다 전파 결과 판정
                ├ 영향 있음: 방향 판정 (같은 방향 / 반대 방향)
                │           받는 코인 충격 = 원래 충격 × 전파 세기 × 받는 코인의 β (반대 방향이면 부호를 바꿈)
                └ 영향 없음: 그 코인의 가격은 이 이벤트로 움직이지 않음
              결과가 반영되는 캔들에 후속 기사 생성 (영향 없음도 포함)
  → 전파 안 되면: 충격이 발생한 코인만 움직임
```

- 전파 확률과 세기의 근거는 실제 데이터의 급등락 전파 통계(F-03)에서 가져온다 **[추측: 데이터로 구분이 될지는 분석해 봐야 앎]**
- 영향 없음 확률과 반대 방향 확률도 같은 통계에서 근거를 찾고, 구분이 안 되면 임시값으로 둔다 **[테스트 후 결정]** (PT-13)
- 전파 대상 코인은 결과와 관계없이 "전파 우려"로 표시한다. 모달이 떠도 등락이 확정되지 않으므로, 전파 여부는 계속 힌트로만 전달된다.
- 후속 기사는 뉴스 피드(F-36)로 보낸다. 예: 영향 없음 → "우려와 달리 영향 제한적", 반대 방향 → "반사 이익 기대감".

### 선택지와 체결 가격 (F-19)

> 모달 동작(일시정지, 직접 주문, 접기, 선택 유도)은 [SCREENS.md](SCREENS.md) S-04a가 기준이다. 아래 모달 관련 항목은 요약.

| 상황 | 처리 |
|---|---|
| 보유 코인에서 충격 발생 | 일시정지, 선택지 |
| 보유 코인이 전파를 받음 | 일시정지, 선택지 |
| 시장 전체 이벤트 | 일시정지, 선택지 |
| 그 밖의 이벤트 | 멈추지 않고 뉴스 피드에 기사로 표시 (F-36) |

| 코인의 위치 | 일시정지 시점의 가격 (선택지 주문의 체결 가격) |
|---|---|
| 충격이 처음 발생한 코인 | 충격이 절반 반영된 가격 |
| 충격이 전파되는 코인 | 충격이 반영되기 전 가격 |
| 시장 전체 이벤트 | 모든 코인에 절반 반영 **[테스트 후 결정]** |

- 진행: 선택 → 주문 체결 → 남은 충격 반영 (즉시 전파 대상 코인의 결과 포함) → 재생 재개
- 일시정지 시점의 가격도 세부 단계 가격 하나로 본다. 모달을 띄우기 전에 그 가격으로 대기 중인 지정가를 먼저 판정하고, 남은 충격이 반영되는 세부 단계에서도 똑같이 판정한다 ([PROCESS.md](PROCESS.md) P-3 순서)
- 늦게 전파된 충격: 처음 이벤트 때 이미 선택지를 줬으므로 모달 없이 뉴스 피드로만 알림. 처음 이벤트 뒤에 대상 코인을 산 경우, 마지막 10캔들이나 600캔들 뒤에 도착하는 경우 등은 3단계 전에 정한다 ([PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md) 8장 #11~14)
- 마지막 10캔들: 게임 마무리를 위해 선택지 대신 뉴스 피드로만 알림
- 같은 캔들에 이벤트가 여러 개일 때: 아래 두 방식을 설정값으로 바꿀 수 있게 구현하고, 실제 테스트에서 나은 쪽을 고른다. **[테스트 후 결정]**
  - A. 묶음: 하나의 모달에 모든 이벤트와 선택지를 함께 표시
  - B. 순서대로: 영향이 큰 이벤트부터 모달을 하나씩 표시
- 선택지 예시: 보유 코인 전량 매도 / 절반 매도 / 그대로 보유 / 현금 30%로 추가 매수 / 직접 주문
- 모달이 떠 있는 동안은 일시정지 상태이고, 선택지를 골라야 재개된다. [그대로 보유]는 "아무것도 하지 않고 재개"
- 직접 주문: 모달 안에서 주문 입력란을 열어 어느 코인이든 여러 건 주문 → [주문 완료하고 재개]. 이 동안 바깥 주문 패널은 잠김
- 사용자가 직접 일시정지(⏸)했을 때는 바깥 주문 패널로 주문 가능

### 주문 (F-16, F-17, F-18)

| 항목 | 규칙 |
|---|---|
| 수량 | 소수점 단위 매매 가능 |
| 최소 주문 금액 | 5,000원 |
| 수수료 | 0.05% (매수·매도 모두) |
| 금액 단위 | 현금·수수료·체결 금액은 원 단위 정수. 수량은 소수 |
| 반올림 | 수수료는 올림, 매도로 받는 금액은 내림 (플레이어에게 불리한 쪽). 평가금액은 표시할 때만 내림 |
| 시장가 | 현재가로 즉시 체결. 슬리피지 없음 |
| 지정가 매수 | 주문 금액(지정가 × 수량)과 수수료만큼 현금을 묶어 둠. 지정가보다 낮은 가격에 체결되면 실제 체결 금액과 수수료를 뺀 나머지를 돌려줌. 취소하거나 판이 끝나면 묶인 현금 전액 반환 |
| 지정가 유지 | 취소 가능. 취소하지 않으면 판이 끝날 때까지 유지 |
| 체결 판정 | 세부 단계 가격이 나올 때마다 판정. 매수는 가격 ≤ 지정가, 매도는 가격 ≥ 지정가. 주문을 넣은 뒤의 세부 단계만 본다. 캔들의 고가·저가는 세부 단계 가격의 최대·최소다 (F-10) |
| 체결 가격 | 판정한 세부 단계의 가격 (실제 거래소처럼 지정가와 같거나 유리한 가격). 가격이 지정가를 건너뛰면 건너뛴 가격에 체결 (예: 100원 → 90원, 지정가 매수 95원 → 90원에 체결). 수량은 주문한 수량 그대로 |
| 공매도·레버리지 | 없음 |
