# Coin Sim — 요구사항 정의

- 작성일: 2026-11-10
- 상태: 확정 (기획 2단계)
- 관련 문서: [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md), [FEATURES.md](FEATURES.md), [PROCESS.md](PROCESS.md)
- 표기 규칙: **[추측]** = 확인되지 않은 사실. 구현 전에 확인한다. / **[임시값]** = 제안한 임시 수치. / **[테스트 후 결정]** = 개발·테스트해 보고 정할 항목 ([PLAYTEST.md](PLAYTEST.md)에 모음)
- 우선순위: **필수** = 1차 출시에 반드시 포함 / **권장** = 가능하면 1차에 포함 / **선택** = 여유가 있거나 2차 이후

## 1. 전제 (확정된 결정)

> 기준: [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md) 2장 "게임 규칙". 수정은 기준 문서에서 먼저.

| 항목 | 값 |
|---|---|
| 플랫폼 | 데스크톱 브라우저만 지원 |
| 한 판 | 캔들 600개 (캔들 1개 = 게임 안 1시간, 게임 안 25일) |
| 배속 | 1배 / 2배 / 3배 → 약 30분 / 15분 / 10분. 템포 값은 설정값으로 분리해 플레이 테스트로 조정 |
| 코인 구성 | 10개, 고정 비율 (대장 1, 대형 2, 중형 3, 소형·밈 4) + 숨은 폭락형 0~1개 (소형·밈 또는 중형 한 자리를 대체, 비공개) |
| 시작 자금 / 수수료 | 1,000만 원 / 0.05% |
| 주문 | 시장가 + 지정가 |
| 섹터 | 2차로 미룸 |
| 수집 범위 | 지금 상장된 업비트 원화 마켓 전체, 1시간 캔들, 전체 기간. 통계가 부족하면 그때 확장 |

## 2. 기능 요구사항

### 데이터

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-01 | 업비트 원화 마켓 1시간 캔들 수집 (요청 제한 준수, 나눠 받기, 끊겨도 이어 받기) | 필수 |
| FR-02 | 통계 추출: 수익률 분포, 변동성, 상태 전환 확률·지속 기간, 급등락 빈도·크기, 급등락 전파, β, 상관관계, 성격 분류 | 필수 |
| FR-03 | 통계를 게임이 읽을 JSON으로 출력 | 필수 |

### 시세 생성

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-04 | 시드 기반 생성 (같은 시드와 통계면 항상 같은 결과) | 필수 |
| FR-05 | 상승·하락·횡보 상태 전환 | 필수 |
| FR-06 | 상태에 맞는 실제 수익률 조각 붙이기 | 필수 |
| FR-07 | 시장 흐름 × β로 코인 간 연관성 반영 | 필수 |
| FR-08 | 가상 코인 10개 생성 (이름, 티커, 소개, 성격, 고정 비율, 숨은 폭락형 0~1개) | 필수 |
| FR-09 | 캔들 안의 세부 움직임 생성 | 필수 |
| FR-10 | 섹터 흐름 (1차에서는 공식에 자리만 남김) | 선택 (2차) |

### 게임 진행

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-11 | 게임 시계: 준비 상태(일시정지로 시작), 재생, 일시정지, 1·2·3배속, 탭 이동 시 자동 일시정지 | 필수 |
| FR-12 | 코인 10개 목록과 실시간 시세 | 필수 |
| FR-13 | 선택한 코인의 캔들 차트 | 필수 |
| FR-14 | 시작 전 과거 캔들을 미리 보여주기 (판단 근거 제공) | 필수 |
| FR-15 | 시장가 주문 | 필수 |
| FR-16 | 지정가 주문 (세부 단계 가격으로 체결 판정, 취소) | 필수 |
| FR-17 | 포트폴리오: 현금, 보유량, 평균 매수가, 평가손익, 수수료 반영 | 필수 |
| FR-18 | 시작 자금 1,000만 원 | 필수 |

### 이벤트

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-19 | 이벤트 생성: 시장 전체, 개별 코인. 이벤트마다 다른 코인으로 전파 여부·세기·범위·시점(즉시 또는 1~3캔들 뒤) 판정. 전파 대상이 되어도 영향 없음·반대 방향일 수 있음 | 필수 |
| FR-20 | 보유 코인이 충격·전파를 받거나 시장 전체 이벤트일 때 일시정지하고 뉴스와 선택지 표시 | 필수 |
| FR-21 | 템플릿으로 뉴스 문구 생성 (전파 여부는 문구로 힌트만 줌). 전파 대상 코인의 결과는 후속 기사로 알림 | 필수 |
| FR-22 | 한 판의 이벤트 횟수와 간격 조절 (너무 몰리거나 없지 않게) | 필수 |
| FR-33 | 선택지를 띄우지 않는 이벤트는 멈추지 않고 뉴스 피드에 기사로 표시 | 필수 |

### 결과와 기록

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-23 | 결과: 최종 수익률, 최대 낙폭 | 필수 |
| FR-24 | "처음에 사서 끝까지 들고 있었을 때"와 비교 | 필수 |
| FR-25 | 등급 (S / A / B ...) | 필수 |
| FR-26 | 선택지별 복기 ("이 시점에 팔았다면 +12%") | 선택 |
| FR-27 | 업적 | 선택 |
| FR-28 | 기록 저장 (localStorage) | 필수 |
| FR-29 | 시드를 입력해 같은 판 다시 하기 | 선택 |
| FR-30 | 저장하고 나가기 → 이어 하기, 새로고침해도 진행 중인 판 복원 | 선택 (2차) |

### 기타

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-31 | 현실감 검증 리포트 (실제 코인과 가상 코인 통계 비교). 개발용이며 게임 화면에는 넣지 않는다 | 필수 |
| FR-32 | 처음 하는 사람을 위한 간단한 도움말 | 선택 |

## 3. 비기능 요구사항

| ID | 구분 | 요구사항 |
|---|---|---|
| NFR-01 | 플랫폼 | 데스크톱 브라우저 (Chrome, Edge, Safari 최신 버전). 최소 해상도 1280×720 **[임시값]** |
| NFR-02 | 플랫폼 | 모바일로 접속하면 데스크톱 이용 안내 화면 표시 |
| NFR-03 | 레이아웃 | 데스크톱 해상도 범위(1280px~와이드 모니터)에서 창 크기에 맞춰 레이아웃 조정 (반응형 레이아웃) |
| NFR-04 | UI 반응성 | 클릭, 호버, 주문 체결, 가격 변화에 즉시 시각적 피드백 (버튼 상태, 가격 변동 강조, 체결 알림 등). 입력 후 100ms 안에 반응 **[임시값]** |
| NFR-05 | 성능 | 3배속(초당 10회 갱신)에서도 끊김 없음. 차트는 선택한 코인 하나만 그림 |
| NFR-06 | 성능 | 게임 시작 시 시세 생성(캔들 600개 × 코인 10개) 1초 이내 **[임시값]** |
| NFR-07 | 성능 | 통계 JSON은 gzip 기준 2MB 이하 **[임시값]** |
| NFR-08 | 재현성 | 시드와 통계가 같으면 같은 차트. 생성 엔진에 테스트 작성 |
| NFR-09 | 구조 | `engine/`과 `game/`은 React에 의존하지 않음. 시세 공급은 `feed` 인터페이스 하나로 통일 |
| NFR-10 | 보안 | 서버와 개인정보 없음. 혼자 하는 게임이라 localStorage 조작은 허용 |
| NFR-11 | 법·고지 | 업비트 이용약관 확인 (통계 공개 배포 가능 여부). 확인 결과: 제5조(데이터 저작권은 두나무, 무단 사용·변경 금지)에 따라 원본은 공개하지 않고 가공 기준을 통과한 통계만 배포 (D-56, [data-spec.md](development/data-spec.md) 부록 A) |
| NFR-12 | 법·고지 | "투자 권유가 아님" 고지. 가상 코인 이름과 티커가 실제 코인과 겹치지 않게 |
| NFR-13 | 표시 규칙 | 상승은 빨강, 하락은 파랑 (국내 거래소 관례). 색만으로 구분하지 않도록 ▲▼ 기호 함께 표시 |
| NFR-14 | 배포 | 정적 사이트 (Vercel, [D-03](development/decisions.md)) |
